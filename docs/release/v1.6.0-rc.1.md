# Trigix 1.6.0-rc.1 technical preview

Trigix 1.6.0-rc.1 is a source and self-hosting release candidate for evaluation,
internal Alpha qualification, and controlled Community Builds. It is not an
Official Trigix Desktop GA release.

## Highlights

- governed Windows and macOS desktop automation through an isolated native Host;
- authenticated Device pairing, health, command leasing, Approval, recovery,
  update policy, fleet compliance, and Audit Log integration;
- consent-gated realtime voice coordination and bounded avatar presentation;
- an isolated Playwright Browser Runtime with secure URL policy, concurrency
  limits, artifact storage, telemetry, and Executor integration;
- PostgreSQL and Redis Streams execution reliability with bounded recovery and a
  dead-letter path; and
- expanded dependency, CodeQL, database, Docker, Helm, Web, Browser Runtime,
  Windows, and macOS qualification gates.

See the [versioned changelog](https://github.com/bj-qizhi/trigix/blob/v1.6.0-rc.1/CHANGELOG.md)
for the detailed change summary.

## Published assets

The GitHub prerelease publishes deterministic source archives, SHA-256 checksums,
an SPDX JSON SBOM, `THIRD_PARTY_NOTICES.md`, bounded release-input evidence, and
Sigstore bundles for build-provenance and SBOM attestations. GitHub also provides
its standard source snapshots.

No Windows installer or macOS DMG in this release is an Official Trigix Desktop
artifact. CI development packages use ephemeral self-issued identities and must
not be redistributed as production-trusted installers.

The matching preview Helm chart is `0.4.0-rc.1` and deploys application version
`1.6.0-rc.1`. Stable installation documentation continues to reference chart
`0.3.6` until a stable promotion decision is recorded.

## Verify the source distribution

Download all named release assets into one directory, then run:

```bash
sha256sum --check trigix-1.6.0-rc.1-SHA256SUMS
gh attestation verify trigix-1.6.0-rc.1-source.tar.gz \
  --repo bj-qizhi/trigix
```

The checksum file covers the source archives, SBOM, notices, and deterministic
release-input evidence. The Sigstore bundles are also attached for offline
verification workflows.

## Supported evaluation boundary

- Self-host the Platform, Executor, AI Runtime, Browser Runtime, Web application,
  PostgreSQL, and Redis using the documented source, Compose, or Helm paths.
- Treat Desktop packages built from this source as development, Community Build,
  or Self-managed Distribution artifacts under the responsibility of their
  named distributor.
- Provide `CREDENTIAL_MASTER_KEY` for persistent Platform deployments and a
  strong `BROWSER_RUNTIME_AUTH_TOKEN` whenever Browser Runtime is enabled.
- Browser Runtime autoscaling requires reviewed S3-compatible artifact storage;
  local ReadWriteOnce storage is limited to a single replica.

## Known limitations and release blockers

- There is no production Windows Authenticode identity or official signed
  Windows installer in this candidate.
- There is no Apple Developer ID, notarized and stapled Official Trigix DMG in
  this candidate.
- Official Desktop GA still requires accepted independent penetration-test,
  malware, clean-device, Alpha, closed-beta, support, legal, and accountable
  promotion evidence.
- Production Linux Desktop distribution remains blocked by the tracked upstream
  GTK3 `glib` advisory. Linux server and container deployments are unaffected.
- Public project support is community support and has no paid uptime or response
  service-level agreement.

## Upgrade and rollback

Back up the database and deployment configuration before upgrading. Exercise
installation, migrations, workflow execution, Browser Runtime policy, Device
reconnect, and rollback in a non-production environment first. To leave the
preview, stop new executions, preserve Audit Log and recovery evidence, restore
the pre-upgrade database snapshot when schema rollback is required, and redeploy
the previously pinned application and chart versions. Do not assume that running
an older binary reverses applied database migrations.
