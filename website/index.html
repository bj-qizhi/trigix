TRIGIX DESKTOP

Local control stays local and interruptible.

AUTOMATION

Semantic actions, not blind replay.

Trigix resolves windows and accessible controls, rejects protected fields, verifies focus, and stops when selectors are stale or ambiguous.

Read the safety model

VOICE

Consent first.

The microphone starts only after a local action. Voice can propose work, but it cannot approve or execute desktop actions by itself.

AVATAR

Presentation only.

The built-in avatar reflects conversation state. It cannot access credentials, approve tools, or operate the computer.

DESKTOP RELEASES

Download only what can be verified.

Production installers are published as immutable GitHub Release assets with a matching SHA-256 checksum. Development-signed qualification builds are never presented here as public releases.
